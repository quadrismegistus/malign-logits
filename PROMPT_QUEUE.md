# Prompt queue — standing ledger of prompts needed, sought, and queued

MAINTAINED BY: registrar (the pen). Created 2026-07-31 at RH's word
([1324]: "a standing ledger for new prompts needed and sought and
queued for the next cloud run"). Companion to `TODO_TRACKS.md`.

Nothing in this file runs by itself. Entries accumulate until a cloud
batch is next justified on other grounds, or RH calls one. Every
entry names the finding or registration it serves, so a prompt with
no consumer never gets authored.

## Lifecycle

    NEEDED -> DRAFTED -> TEMPLATE-AUDITED -> RH CONSTRUCT READ
           -> QUEUED FOR NEXT CLOUD RUN -> RUN

- DRAFTED: a Sonnet agent drafts against the governing template,
  ~3x oversample (drafting is not the epistemically loaded step;
  the gates are).
- TEMPLATE-AUDITED: lacan checks template conformance; malign checks
  fields and catalogue fit. Authored facts at birth, always:
  pair_id, pair_role keyed to the transgressive flag, contrast_type
  on BOTH members, domain, language, writer named at the line that
  sets pair_role ([1275].2, [1276], [1316]).
- RH CONSTRUCT READ: RH reads the survivors' strings — the decisive
  filter (4/4 exclusions today were his readings).
- Size to YIELD, not count ([1316].4): an authored pair is not a
  usable pair; both members must clear the displacement bar
  (~half qualify at 0.02, ~1/50 at 0.10).
