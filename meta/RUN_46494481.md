## What the run writes

Per prompt, flushed immediately, both writers:

    {model}.jsonl   word probabilities, rule_version 3, + logit_row /
                    logit_dim / logit_dtype

                    vocab_size*2 bytes; row n IS the nth logit-bearing line

**float16 on RH's ruling** — the pre-existing store was MIXED (49 models f16,
87 f32) and a uniform store is worth more than a marginally more precise one
that cannot be compared across its own rows. The fold is a PURE SIDE EFFECT:
`lg` already existed, the call is batch-1, no RNG is consumed, and word-prob
values are bit-identical. **No v3->v4: RULE_VERSION versions the WORD-BOUNDARY
RULE and a logit vector segments nothing.**
